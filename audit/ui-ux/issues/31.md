## Problem

The public intake form has two feedback gaps:

1. **Required title is unmarked.** Title is the only required field but has no visible required marker or help text. Submitting empty triggers only a transient native browser bubble, while submitting whitespace produces the page's persistent inline error. The same rule gets two different treatments.
2. **Success omits the submission reference.** The success view has a `Reference` row ready, but the action returns only `{ submitted: true }`, so the row never renders. The submitter gets confirmation but no identifier to quote to a triager, and "Copy Link" copies only the current page URL.

## Affected routes

- `/intake` at desktop and mobile, light and dark.

## Steps to reproduce

1. Open `/intake` and click Submit with both fields empty; then enter three spaces in Title and submit again.
2. Submit a valid title and description and read the success panel.
3. Inspect `form.ref` / the returned action data.

## Actual behavior

- Empty submit: native bubble, no inline error; whitespace submit: red border and persistent "A title is required." The label never says required.
- Success: "Issue Submitted", "Staged for triage", Copy Link, Submit Another — no reference number; `form.ref` is undefined.

## Expected behavior

Title is visibly marked required and both invalid paths produce the same persistent, announced inline error linked to the field. The success state shows a stable reference the submitter can quote.

## Impact

First-time public submitters cannot tell which field is required and may miss the transient native message. Without a reference, they cannot follow up on their submission.

## Suggested direction

Add a required marker and route empty submits through the same server-rendered inline error (or call `reportValidity` and also render the inline message). Return `ref: id` from the action and render it; if the internal id should not be public, derive a short opaque reference at staging time.

## Acceptance criteria

- [ ] The required Title field is visibly marked.
- [ ] Empty and whitespace submissions produce the same persistent, announced inline error.
- [ ] The error is linked to the field via `aria-describedby`.
- [ ] The success state displays a stable reference for the staged submission.

**Priority:** P3 — public form feedback is incomplete.

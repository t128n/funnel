## Problem

Breadcrumbs are applied inconsistently and are not labelled. `/issues` renders `Workspace / Issues`, but `/epics`, `/milestones`, `/notifications` and `/attention` have none. `/epics/<owner>/<repo>/<n>` has no breadcrumb and no direct link back to Epics; `/milestones/.../n` substitutes a right-aligned "← Milestones" button for a breadcrumb. Every breadcrumb also renders `<nav class="mb-2">` without `aria-label="breadcrumb"`, so the page has multiple unnamed navigation landmarks.

## Affected routes

- `/epics`, `/epics/[owner]/[repo]/[number]`, `/milestones`, `/milestones/[owner]/[repo]/[number]`, `/notifications`, `/attention`; all pages that render a breadcrumb.

## Steps to reproduce

1. Open `/issues` and note the breadcrumb.
2. Open `/epics` and `/epics/demo/funnel/10`; no breadcrumb appears and there is no link back to Epics.
3. Inspect `document.querySelectorAll('main nav')` on `/issues`; the breadcrumb nav has no accessible name.

## Actual behavior

Organization pages start directly at the heading. The epic detail is a navigation dead end apart from browser history or More → Epics. Milestone detail uses a different back pattern. Breadcrumb landmarks are unlabelled.

## Expected behavior

Every index and detail page carries the same Bootstrap breadcrumb (`Workspace / Epics / demo/funnel#10`) with the current item marked, and each breadcrumb nav is labelled "breadcrumb". Epic detail links directly back to Epics.

## Impact

Users lose their location in deep organization pages and must rediscover the overflow menu. Screen-reader users cannot distinguish breadcrumb navigation from the app bar in a landmark list.

## Suggested direction

Add `Breadcrumb`/`BreadcrumbItem` to the organization routes, replace the milestone back button with it, and pass `aria-label="breadcrumb"` through a single shared breadcrumb wrapper.

## Acceptance criteria

- [ ] Each organization index shows `Workspace / <Section>`.
- [ ] Epic and milestone details show the parent section in a breadcrumb.
- [ ] Epic detail has a direct link to `/epics`.
- [ ] Every breadcrumb nav has the accessible name "breadcrumb".
- [ ] No unnamed navigation landmarks remain on index or detail pages.

**Priority:** P2 — recurring navigation inconsistency and dead ends.

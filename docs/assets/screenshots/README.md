# Documentation screenshots

This directory contains two kinds of images:

- **Guide screenshots** under `<guide>/<nn>-<action>-<state>.png`, generated by the scripted workflow and checked against [`docs/screenshots/manifest.json`](../../screenshots/manifest.json). See the [capture workflow](../../screenshots/README.md) for regeneration, guide references, safety rules and manual exceptions.
- **Historical design and feature captures** at the root of this directory and in `pr/`. These are referenced by design evidence and older feature pages. The capture workflow lists every file under `docs/assets/screenshots/`; do not delete an image merely because it is not in the guide manifest.

## Guide screenshot workflow

```sh
bun docs/screenshots/capture.ts capture all --replace
bun docs/screenshots/capture.ts check
```

The first command starts an isolated demo database, captures every scenario in
the manifest with `agent-browser`, and writes the images here. The second
verifies that every manifest image exists and is referenced by at least one
mapped guide, and that no unmanifested generated image remains.

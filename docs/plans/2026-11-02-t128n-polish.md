# Funnel UI polish pass — t128n

**Status:** Implemented and validated on `feat/t128n-redesign`.

**References:** `docs/DESIGN.md`, `src/lib/styles/tokens.css`,
`src/lib/styles/theme.css`, and the t128n `DESIGN.md` / `PATTERNS.md` in the
workspace skill. No repository-level `AGENTS.md` exists.

## Global acceptance criteria

- Existing routes, data flow, mutations, filtering, URL state, keyboard
  behavior, permissions, and feature flags are preserved.
- Colors, spacing, sizes, radii, and motion use the existing token variables.
  No new dependency and no unrelated refactor.
- Standard form fields and buttons are 36px (`--size-control-md`). 28px
  (`--size-control-sm`) is reserved for dense toolbars, row actions, menus, and
  icon utilities.
- Labels sit 4px above fields; closely related controls 8px apart; toolbar
  groups 16px apart; form fields 24px apart; major sections 32px apart;
  desktop workspace padding is 24px (`--layout-page-padding`).
- Primary buttons use `on-primary`; destructive buttons use `on-error`.
- Both themes, 320–390px, 200% text, keyboard focus, and local overflow are
  checked for every affected surface.

  toolbars, row actions, menus, and icon utilities; primary buttons use
  `on-primary` and long icons resolve to 1.25rem. Main and settings navigation
  both use 36px rows, 8px padding, 16px icons, and the same selected treatment.
  Toolbar groups are 16px apart; form fields 24px; major sections 32px.

  epic relationship, compact expanding composer with draft retention.

  longer struck through.
- **T4 Planning:** explicit net/cap/scheduled labels; shared committed/cap
  denominator; allocation marker removed; stable size/estimate/action columns;
  compact empty groups; mobile two-line issue rows.
- **T5 Appearance/Intake:** spacing-only theme grouping, no separators, resolved

  emphasis Copy Draft Link.
- **Integration:** 200% text keeps a usable list viewport and scrolls the
  surrounding workspace rather than collapsing it; read-only roles hide

### Deliberate deviations

- Dense toolbar, row, and menu controls retain the 1.75rem token; standard forms
  and page actions use 2.25rem.
- At 200% text on a narrow viewport, the workspace scrolls and the list keeps a
  30svh minimum rather than clipping. No horizontal page scroll.
- Theme persistence keeps the application-specific `funnel:theme` key and the
  `.dark` compatibility class; components key off `data-theme`.

No repository-level `AGENTS.md` exists in the repository, workspace root, or
worktree; the implementation followed the repo design docs plus the current
`t128n/design` skill references.

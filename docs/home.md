# Funnel documentation

Funnel is a self-hosted GitHub issue cockpit with a public intake queue and a local issue mirror.

## Start here

- **New to Funnel?** [Get started](tutorials/getting-started.md), then [triage a backlog](tutorials/triage-a-backlog.md).
- **Using Funnel every day?** Explore [issues](how-to/use/create-and-edit-issues.md), [the board](how-to/use/board.md), [planning](how-to/use/plan-work.md), [attention](how-to/use/attention.md), [insights](how-to/use/insights.md), and [notifications](how-to/use/notifications.md).
- **Operating an instance?** Start with [installation](how-to/deploy/install.md), the [production checklist](how-to/operate/production-checklist.md), [roles](how-to/configure/people-and-roles.md), and [backup and restore](how-to/operate/backup-and-restore.md).
- **Integrating?** Read the [intake API guide](how-to/integrate/intake-api.md) and [HTTP API reference](reference/http-api.md).
- **Looking for a setting?** See [environment variables](reference/environment-variables.md), [settings](reference/settings.md), and [roles and permissions](reference/roles-and-permissions.md).

For background, see the [architecture](explanation/architecture.md), [workflow](explanation/workflow-model.md), and [security model](explanation/security-model.md).
